# Black Stag Reliquary

A buildless static art gallery for Randall Farmer. Website files are kept in `dist/` so they can also be previewed locally. The gallery shows optimized framed display images only; original photographs and print masters stay out of this repository.

The GitHub Pages workflow publishes `dist/` when enabled for the repository. Texture photo credits and source licenses appear on the gallery's Materials & image credits page.
